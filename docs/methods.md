preprocessing inside sklearn `Pipeline`, estimator execution, optional Optuna tuning, metrics, plots,
and run artifacts. Gradient boosting examples also compare sklearn with XGBoost, LightGBM, and
CatBoost. Every run logs a `metric_interpretation` tag to MLflow — see [mlflow.md](mlflow.md).
